# Propriétés des atomes réutilisables

Les cinq atomes sont indépendants du magasin du quiz et de l’API. Leurs propriétés publiques restent compatibles avec le projet Todo List et permettent de les réutiliser dans d’autres applications.

## Conventions communes

| Propriété                  | Valeurs ou rôle                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------- |
| `size`                     | `xs`, `sm`, `md`, `lg`, `xl`. Valeur par défaut : `md`.                               |
| `radius`                   | `none`, `sm`, `md`, `lg`, `full`. Omettre la propriété conserve l’arrondi par défaut. |
| `className`                | Classes CSS supplémentaires, ajoutées aux classes de base et de variante.             |
| `style`                    | Styles natifs, y compris les variables CSS de personnalisation.                       |
| `ref`                      | Accès à l’élément natif : bouton, champ, liste, zone de texte ou span.                |
| `id`, `title`              | Identifiant et infobulle natifs.                                                      |
| `aria-*`, `data-*`         | Attributs d’accessibilité et données personnalisées transmis à l’élément natif.       |
| Gestionnaires d’événements | `onClick`, `onFocus`, `onBlur`, `onKeyDown` et les autres événements pris en charge.  |

Utilisez directement les attributs HTML natifs. Les boutons acceptent notamment `form`, `formAction`, `tabIndex` et `name`. Les champs acceptent `min`, `max`, `pattern`, `maxLength` et `autoComplete`. Les propriétés natives non énumérées sont transmises avec `...props`.

## Button — Bouton

| Propriété                      | Par défaut | Rôle                                                                                     |
| ------------------------------ | ---------- | ---------------------------------------------------------------------------------------- |
| `variant`                      | `primary`  | `primary`, `secondary`, `ghost`, `danger`, `success`, `outline`, `link`.                 |
| `children`, `label`            | —          | Contenu. `label` sert de texte de remplacement si `children` est absent.                 |
| `type`                         | `button`   | Type HTML : `button`, `submit` ou `reset`.                                               |
| `disabled`                     | `false`    | Désactive les interactions.                                                              |
| `loading`                      | `false`    | Affiche un indicateur de chargement, désactive le bouton et expose `aria-busy`.          |
| `loadingLabel`                 | —          | Texte facultatif pendant le chargement ; sinon, le nom accessible existant est conservé. |
| `startIcon`, `endIcon`         | —          | Éléments React décoratifs avant ou après le contenu.                                     |
| `fullWidth`                    | `false`    | Occupe toute la largeur disponible.                                                      |
| `id`, `name`, `value`, `title` | —          | Attributs HTML natifs du bouton.                                                         |
| `autoFocus`                    | `false`    | Place le focus au montage.                                                               |
| `onClick`, `onFocus`, `onBlur` | —          | Fonctions de rappel natives.                                                             |

```jsx
<Button
  variant="success"
  size="lg"
  radius="full"
  startIcon={<Check />}
  fullWidth
  loading={submitting}
  loadingLabel="Vérification…"
  onClick={submitAnswer}
>
  Vérifier la réponse
</Button>
```

## Input — Champ de saisie

| Propriété                             | Par défaut        | Rôle                                                                                             |
| ------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------ |
| `as`                                  | `input`           | Élément natif : `input`, `textarea` ou `select`.                                                 |
| `variant`                             | `default`         | `default`, `filled` ou `underline`.                                                              |
| `type`                                | `text`            | Type HTML, par exemple `email`, `password`, `number`, `date` ou `search`. Uniquement pour input. |
| `value`, `defaultValue`               | —                 | Valeur contrôlée ou valeur initiale non contrôlée. Choisir l’une des deux.                       |
| `onChange`, `onFocus`, `onBlur`       | —                 | Fonctions de rappel natives du champ.                                                            |
| `name`, `placeholder`, `autoComplete` | —                 | Attributs HTML natifs du champ.                                                                  |
| `disabled`, `required`, `autoFocus`   | `false`           | Interaction, validation et focus natifs.                                                         |
| `readOnly`                            | `false`           | Lecture seule pour input et textarea. Non applicable à select.                                   |
| `invalid`                             | `false`           | Style d’erreur et `aria-invalid`. Un attribut `aria-invalid` explicite est également accepté.    |
| `fullWidth`                           | `true`            | Occupe toute la largeur disponible ; `false` conserve la largeur intrinsèque.                    |
| `htmlSize`                            | —                 | Attribut HTML `size`, distinct de la taille visuelle définie par `size`.                         |
| `resize`                              | CSS du navigateur | Redimensionnement de textarea : `none`, `vertical`, `horizontal` ou `both`.                      |
| `options`                             | —                 | Tableau facultatif de `{ value, label, disabled }` pour select. Les enfants sont prioritaires.   |
| `children`                            | —                 | Options ou groupes d’options pour select. Aucun enfant pour input.                               |

```jsx
<Input
  name="answer"
  value={answer}
  onChange={(event) => setAnswer(event.target.value)}
  required
  maxLength={120}
  invalid={hasError}
  aria-label="Votre réponse"
  aria-describedby="answer-help"
/>

<Input
  as="select"
  name="difficulty"
  defaultValue="easy"
  aria-label="Difficulté"
  options={[
    { value: 'easy', label: 'Facile' },
    { value: 'hard', label: 'Difficile' },
  ]}
/>
```

Un champ contrôlé met à jour sa valeur dans `onChange`. Un champ non contrôlé utilise `defaultValue`. Ajoutez les étiquettes et les messages d’aide ou d’erreur dans une molécule afin de conserver un atome indépendant du formulaire.

## Checkbox — Case à cocher

| Propriété                           | Par défaut | Rôle                                                                         |
| ----------------------------------- | ---------- | ---------------------------------------------------------------------------- |
| `variant`                           | `default`  | `default`, `primary` ou `danger`.                                            |
| `checked`, `defaultChecked`         | —          | État contrôlé ou état initial non contrôlé. Choisir l’un des deux.           |
| `indeterminate`                     | `false`    | État mixte natif, par exemple lorsque certaines réponses sont sélectionnées. |
| `invalid`                           | `false`    | Style d’erreur et `aria-invalid`.                                            |
| `disabled`, `required`, `autoFocus` | `false`    | Attributs natifs de la case à cocher.                                        |
| `name`, `value`                     | —          | Attributs natifs de soumission du formulaire.                                |
| `onChange`                          | —          | Reçoit l’événement React natif de changement.                                |
| `onCheckedChange`                   | —          | Reçoit `(checked, event)` pour manipuler directement un booléen.             |
| `onFocus`, `onBlur`                 | —          | Fonctions de rappel natives.                                                 |

```jsx
<Checkbox
  variant="primary"
  name="answers"
  value="a"
  checked={selected}
  onCheckedChange={setSelected}
  aria-label="Sélectionner la réponse A"
/>
```

Pour une case à état mixte, mettez à jour `checked` et `indeterminate` dans le composant propriétaire lors d’un changement. La propriété `ref` donne accès au champ natif.

## Badge

| Propriété              | Par défaut           | Rôle                                                                                           |
| ---------------------- | -------------------- | ---------------------------------------------------------------------------------------------- |
| `variant`              | `neutral`            | `neutral`, `primary`, `high`, `medium`, `low`, `danger`, `warning` ou `success`.               |
| `appearance`           | `soft`               | `soft`, `outline` ou `solid`.                                                                  |
| `children`, `label`    | —                    | Contenu ou texte de remplacement. Les nombres sont acceptés.                                   |
| `dot`                  | `false`              | Ajoute un point décoratif.                                                                     |
| `startIcon`, `endIcon` | —                    | Éléments React décoratifs.                                                                     |
| `onRemove`             | —                    | Affiche un bouton de suppression et reçoit son événement de clic. Le parent supprime le badge. |
| `removeLabel`          | `Supprimer le badge` | Nom accessible du bouton de suppression. Privilégier une étiquette contextuelle.               |
| `disabled`             | `false`              | Atténue le badge et désactive son bouton de suppression.                                       |

```jsx
<Badge
  variant="warning"
  appearance="outline"
  radius="full"
  startIcon={<Star />}
  onRemove={() => removeCategory('science')}
  removeLabel="Supprimer la catégorie Science"
>
  Science
</Badge>
```

## IconButton — Bouton avec icône

| Propriété             | Par défaut | Rôle                                                                     |
| --------------------- | ---------- | ------------------------------------------------------------------------ |
| `label`               | —          | Nom accessible obligatoire pour chaque bouton ne contenant qu’une icône. |
| `children`, `icon`    | —          | Contenu de l’icône. Les enfants sont prioritaires.                       |
| `variant`             | `ghost`    | Mêmes variantes que Button.                                              |
| `type`                | `button`   | Type HTML du bouton.                                                     |
| `title`               | `label`    | Infobulle personnalisée facultative.                                     |
| `loading`, `disabled` | `false`    | Chargement et désactivation hérités de Button.                           |
| `loadingLabel`        | —          | Nom accessible facultatif pendant le chargement.                         |
| `pressed`             | —          | Valeur `aria-pressed` facultative pour les boutons à bascule.            |
| `onClick`             | —          | Gestionnaire de clic natif.                                              |

IconButton partage les attributs natifs, événements, références, tailles et arrondis de Button. Ses dimensions restent carrées ; `radius="full"` lui donne une forme circulaire.

```jsx
<IconButton
  icon={<Star />}
  label="Marquer la question"
  radius="full"
  pressed={bookmarked}
  onClick={() => setBookmarked((current) => !current)}
/>
```

Les exemples de chaque atome présentent ces états. Tous les styles utilisent des modules CSS et des variables de thème partagées. Aucun paquet supplémentaire n’est nécessaire.
