# Bibliothèque de composants QuizApp

Un quiz React organisé selon la même architecture Atomic Design que le projet Todo List voisin.

## Explorer les composants

- **Atomes :** Button, IconButton, Input, Checkbox et Badge conservent leurs API publiques, attributs HTML, références, variantes, tailles, arrondis et classes personnalisées. Consultez **Atomes / Référence des propriétés**.
- **Molécules :** choix de réponse natifs, liens de navigation entre les questions, compte à rebours, fenêtre modale accessible et corrigé de question.
- **Organismes :** navigation des questions, carte de question, suivi du quiz et résultats.
- **Modèles :** disposition complète et adaptative du quiz. Sélectionnez des réponses et naviguez sans modifier votre véritable tentative.

Utilisez le menu **Thème** pour afficher les versions claire et sombre. Les contrôles permettent de modifier les propriétés ; les interactions sont consignées dans le panneau des actions. Le panneau d’accessibilité permet d’inspecter chaque exemple.

## Style et accessibilité

Chaque composant visuel possède un fichier JSX et un module CSS. Les couleurs, espacements, tailles de texte, arrondis, animations et dimensions des contrôles sont centralisés dans `src/styles/tokens.css`. Les atomes sont indépendants de l’état du quiz et de l’API.

Les réponses utilisent des boutons radio natifs : Tab entre dans le groupe, les flèches changent la sélection et Espace sélectionne la réponse ciblée. Les fenêtres modales natives contiennent le focus, se ferment avec Échap et restaurent le focus à la fermeture. Le compte à rebours n’interrompt pas les lecteurs d’écran chaque seconde. Les préférences de réduction des animations sont respectées.

## État et API simulée

`quizModel.js` valide les données et définit les transitions immuables, les calculs de durée et les statistiques finales. `quizStore.js` gère la tentative, le stockage local versionné et l’échéance. `useQuiz.js` relie React au magasin avec `useSyncExternalStore`. Les composants reçoivent leurs données et fonctions de rappel par leurs propriétés.

Tous les textes de l’application et des exemples sont en français. Les anciennes tentatives compatibles sont traduites à la restauration en conservant les réponses, la question actuelle et l’échéance. Les noms techniques des propriétés, variantes et API restent inchangés.

Lancez `npm run start:mock` pour servir les questions avec WireMock sur le port 8080. L’application fonctionne également sans WireMock grâce aux données intégrées. Le point d’accès POST accuse uniquement réception : les réponses et résultats sont conservés dans localStorage, sans base de données distante.

Le README du projet présente l’installation, la configuration, les commandes et la liste des vérifications.
